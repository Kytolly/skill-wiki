# Mode: policy-procedure

## 适用场景
- 公司/组织规章制度
- 审批、流程、合规文档
- 需要规范性权威来源

## 内容组织
- Rule → Objective → Scope → Applicability → Procedure → Responsibility → Review
- 编号与版本管理

## Source Hierarchy（优先级从高到低）
1. Official Policy / Regulation
2. Authoritative Procedure
3. Official Documentation
4. Trusted Web Source
5. General Model Knowledge

## Completeness Policy

Rule-complete：条款不得删减；不得为流畅而改写规范语义。

## Terminology Policy

保留规范术语（MUST/SHOULD/MAY、Responsible、Approver）。

## Evidence Policy

每条条款有条款编号 + 生效日期 + 权威来源。

## Figure Policy

流程图/组织图标注来源。

## 页面结构与特殊元素
- Rule ID
- Objective
- Scope
- Applicability
- Procedure
- Responsibility
- Review
- Version history

## QA 重点
- [ ] 条款完整
- [ ] Severity/用词语义不变
- [ ] 责任/审批明确
- [ ] 生效日期/来源存在
