# Mode: technical-tutorial

## 适用场景
- 面向零基础/初学者的入门教程
- 保留现有 skill 的 Why-first 强项
- 目标是让新手跑通 demo 并建立学习路径

## 内容组织
- Why first → analogy → minimal runnable demo → FAQ → exercises → learning path → quick reference

## Source Hierarchy（优先级从高到低）
1. Official Documentation
2. Primary Source / Spec
3. Authoritative Secondary Source
4. Trusted Web Source
5. General Model Knowledge

## Completeness Policy

Minimum viable learning path allowed：可用“最小必要知识”，但每个新概念仍需解释或链接。

## Terminology Policy

canonical English term 保留，中文辅助；首次出现写“中文（Canonical English, ABBR）”。

## Evidence Policy

statically 可验证的步骤（命令、版本号、API）要有来源；教学性解释可标为 Explanation。

## Figure Policy

官方图优先；找不到可靠图用 Mermaid，且标注 Conceptual illustration; not present in source.。
