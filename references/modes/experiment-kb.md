# Mode: experiment-kb

## 适用场景
- 实验过程记录、复现
- 实验数据/参数/结果/结论
- 需要可复现性与追溯

## 内容组织
- Experiment → Objective → Setup → Method → Data → Result → Conclusion → Reproduction
- 每步记录时间/参数/环境/观察

## Source Hierarchy（优先级从高到低）
1. Experiment Log / Instrument Log
2. Official Protocol
3. Primary Source
4. Trusted Web Source
5. General Model Knowledge

## Completeness Policy

Reproducibility-oriented：环境、参数、数据、异常、结论必须完整可复现。

## Terminology Policy

保留仪器/方法/参数名；规范术语。

## Evidence Policy

每个观察/结论对应实验记录（时间、仪器、参数、原始数据）。

## Figure Policy

实验图/曲线必须标注来源与采集参数。

## 页面结构与特殊元素
- Objective
- Setup
- Method
- Data
- Result
- Conclusion
- Reproduction
- Known issue

## QA 重点
- [ ] 可复现信息完整
- [ ] 参数有记录
- [ ] 数据/结论有来源
- [ ] 异常有记录
