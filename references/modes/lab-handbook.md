# Mode: lab-handbook

## 适用场景
- 实验室/生产环境的操作规范
- Safety 优先的 SOP
- 规则需要权威来源与版本控制

## 内容组织
- Rule completeness 优先
- Safety first；程序/清单/设备/应急/事件/责任人/修订历史

## Source Hierarchy（优先级从高到低）
1. Authoritative Regulation / Institutional Policy
2. Laboratory Director / PI 明确规则
3. Official Safety Standard
4. Published Lab Manual
5. Trusted Web Source
6. General Model Knowledge

## Completeness Policy

Rule-complete：规则必须完整；不得为“新手友好”弱化警告或擅改规范语义。

## Terminology Policy

规范术语（MUST/SHOULD/MAY、PPE、HAZMAT 等）必须保留规范语义。

## Evidence Policy

每条规则要有 Rule ID + Severity + Source authority；不要把解释写成原规则。

## Figure Policy

安全图示（PPE、紧急出口、设备图示）必须标注来源与访问日期。

## 页面结构与特殊元素
- Rule ID
- Severity（MUST/SHOULD/MAY）
- Applicability
- Responsible role
- Procedure
- Prerequisite
- Required PPE
- Warning
- Emergency action
- Revision history
- Source authority

## QA 重点
- [ ] 规则完整无删除
- [ ] Severity 语义未被弱化
- [ ] PPE/应急步骤完整
- [ ] 规则有权威来源
- [ ] 修订历史存在
