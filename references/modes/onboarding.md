# Mode: onboarding

## 适用场景
- 团队新人入职/交接
- 内部知识库
- 需要快速定位关键入口与责任

## 内容组织
- Role target → First week tasks → Core tools → Key contacts → Policies → FAQ
- 按角色/目标映射内容

## Source Hierarchy（优先级从高到低）
1. Team-internal Docs / Code / Runbooks
2. Official Internal Policy
3. Official Documentation
4. Trusted Web Source
5. General Model Knowledge

## Completeness Policy

## Figure Policy
