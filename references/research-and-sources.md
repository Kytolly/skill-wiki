# 联网调研与来源记录规范

每次生成或更新页面前，先为"本批页面"做调研，而不是为整个知识库做一次性调研。

## 调研目标

- 确认本批页面的技术信息准确且最新。
- 获取真实、可运行的代码示例和官方用法。
- 了解行业最新动态、最佳实践和版本变化。
- 找到优质学习资源，放入页面末尾"延伸阅读"。
- 为本批页面找配图素材（官方图优先，见 references/figure-conventions.md）。

## 调研方式（按可用工具选择）

- 用可用的联网搜索工具（web_search / Tavily / WebSearch 等）搜索最新信息。
- 抓取官方文档、官方教程、权威教材或知名社区教程。
- 涉及编程库或框架时，查询最新文档与版本说明。
- 没有联网能力时，明确告诉用户信息截止到你的知识日期，并在页面标注"信息可能已过时"。

## 记录来源

- 每个页面的"更新日志"记录来源 URL 与访问日期。
- 关键事实（版本号、命令、API 名称）必须能在来源中找到，不确定时立即搜索确认，不要猜。
- 来源不可访问时，不要编造 URL；宁可删除该事实或标注"待确认"。
- 配图来源同样记录 URL + 访问日期；禁止编造图片 URL。

## 版本与时效性

- 涉及软件安装时，写明操作系统、软件版本或"当前最新稳定版"及验证日期。
- 安装步骤要能被一个新手照着跑通：命令完整、路径明确、验证方法清晰。
- 示例代码要优先使用官方 demo 或最小可复现示例，而不是大段伪代码。
