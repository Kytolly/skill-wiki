# Git 知识库

给完全没学过 Git 的人的分级讲义，目标是从"听说过 Git"逐步走到"能独立管理自己的项目"。

## 学习地图

| 分级 | 目标 | 页面 | 状态 |
|------|------|------|------|
| 入门（basics） | 理解版本控制，能安装 Git 并跑通一次提交 | [[Git是什么与第一次提交]] | 已完成 |
| 实战（practice） | 会建分支、合并、推送到远程仓库 | 规划中 | 规划中 |
| 进阶（advanced） | 会解决冲突、回退、理解常见工作流 | 规划中 | 规划中 |

## 分级说明

本知识库采用"按任务自定"分级：`basics → practice → advanced`。每个分级只引入 5-7 个新核心概念，跨度太大时会拆子级。

## 学习顺序

从 [[Git是什么与第一次提交]] 开始，逐级向下。每页末尾都有"下一步"。
