# Git 知识库

给完全没学过 Git 的人的分级讲义，目标是从“听说过 Git”逐步走到“能独立管理自己的项目”。

## 学习地图

| 层级 | 目标 | 页面 | 状态 |
|------|------|------|------|
| L0 概念启蒙 | 理解版本控制，能安装 Git 并跑通一次提交 | [[L0-Git是什么与第一次提交]] | 已完成 |
| L1 入门 | 会建分支、合并、推送到远程仓库 | 规划中 | 规划中 |
| L2 进阶 | 会解决冲突、回退、理解常见工作流 | 规划中 | 规划中 |
| L3 高级 | 会 rebase、tag、子模块、性能与安全 | 规划中 | 规划中 |
| L4 专家 | 能设计团队工作流、维护大型仓库 | 规划中 | 规划中 |

## 分级说明

本知识库采用通用五级模型。每个层级只引入 5-7 个新核心概念，跨度太大时会拆成子级。
